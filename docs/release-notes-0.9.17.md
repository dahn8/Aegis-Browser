# Aegis Browser 0.9.17

轻量、隐私优先的 Android 浏览器外壳（系统 WebView），零后台、零遥测、零账号。

## 本次更新

### 界面修复
- 横屏首页重排：A 标识缩小并上移、搜索框抬高、快捷方式完整排在搜索框下方，不再被底部导航截断
- 横屏主菜单改为右侧悬浮面板：宽度约屏宽 38%、上限 400dp、垂直居中，不再铺满整屏或缩成窄条
- 竖屏打开菜单后旋转横屏，菜单按新窗口尺寸重新排版，不再缩在右侧
- 修复横屏转回竖屏后首页 A 标识消失
- 「添加快捷方式」弹窗标题与输入框对齐，不再超出卡片边框
- 「关于 Aegis」只保留版本号

### 隐私加固（M6）
- 新增反指纹基线：统一 navigator 平台/厂商/硬件参数，与 UA 自洽（隐私设置可关）
- 注入 Referrer 策略 `strict-origin-when-cross-origin`，跨站只带源、不泄露路径
- 新增「拦截记录」页：列出最近被规则拦下的域名与来源页面，误伤可一键加入白名单
- 无痕模式零落盘：不写入最后访问地址、不保存标签会话，退出与销毁时统一清理
- HTTPS-Only、第三方 Cookie 拦截、DNT/GPC、跟踪参数剥离延续原有默认

### 工程
- 新增 `Release APK` 工作流：推送 `v*` 标签自动出包并创建 GitHub Release
- 新增 F-Droid 元数据（fastlane）与应用市场描述

## 安装
- Debug 签名，覆盖安装前请先卸载旧版
- 权限：网络、震动、相机（仅扫码）、安装更新包；不申请存储、定位、通讯录、短信

## 已知限制
- 依赖系统 WebView，网页兼容性随系统 WebView 版本
- 加密 HLS / fMP4 视频无法解封装
