# Aegis Browser v0.9.18

首个使用正式发布密钥签名的版本，`versionCode 138`。

## 新增

- 设置 → 关于 → 检查更新：读取 GitHub Releases 最新版本并逐段比较版本号；接口限流或异常时自动回退到 `releases.atom`；发现新版本可直接跳转 Release 下载页。

## 变更

- 彻底移除 F-Droid 提交材料与相关计划，分发渠道统一为 GitHub Releases。
- README 修正权限说明，补充本地与 CI 的 Release 签名方式。
- 自动发布工作流改为构建 `assembleRelease`，使用正式签名密钥，并在 CI 内校验 APK 签名。
- M6 自检清单更新为正式签名发布链路与应用内检查更新验证。

## 安装说明

- v0.9.17 使用 debug 签名，与本版正式签名不兼容，无法直接覆盖安装。请先卸载旧版再安装 v0.9.18。
- 卸载会清除本地设置、书签与浏览数据，如有需要请提前备份。
